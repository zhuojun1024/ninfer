KV cache 量化与上下文深度：固定文本金标准对照

Qwen3.8-27B-Coder390-EfficientThink-W4A4-W8A8-Vision · TP-2 --devices 0,1 · 被打分的文本固定为源流最后 1024 个 token · 每次运行只改"能看到多长的前文"

为什么这个设计能回答"上下文变长会不会变差"

上一版把一条 257K 的自然流一次跑完，逐 token 看 NLL —— 深度和文本内容是绑死的（越深的 token 越属于后面的书），所以"模型随上下文变差"分不清是深度还是文本。

这一版把被打分的文本钉死：目标块恒为源流最后 1024 个 token，第 K 次运行只暴露它前面 K 个 token。K ≥ 1 时目标块的紧邻前文每次都是同一段文字，连拼接接缝都不存在，唯一变量是历史能看到多远。横轴是某个 token 的实际历史长度；同一横轴位置各条臂打的是同一个 token，所以臂间差与深度间差都是严格配对的。

已校验：13 条输入流的末尾 3000 字符逐字节相同（每条都是源流的字符后缀），所以被打分的 1008 个 token 在每次运行里严格是同一段文本。

唯一的残留混淆：历史的内容随 K 变化 —— 源流是 pg19 四本书顺序拼接，可见窗口跨过书边界时，前文换成了另一本书。所以"相邻深度配对差"同时混了"更多历史"与"不同历史"两个因素，逐点因果不能下；能下的是长期趋势。

结论

问题一：同一段文本，历史越长，模型是变好还是变差？

把被打分的文本钉死之后，所有臂的 NLL 随可见历史的斜率都是负的：bf16 -0.168795 ± +0.032161 nats/十倍程（t=-5.25）；int8 -0.109210 ± +0.021811 nats/十倍程（t=-5.01）；fp8 -0.119033 ± +0.021986 nats/十倍程（t=-5.41）；nvfp4 -0.119770 ± +0.023345 nats/十倍程（t=-5.13）；k8v4 -0.116536 ± +0.022157 nats/十倍程（t=-5.26）。最平的一条（int8）也达到 t=-5.01，也就是说"历史越长，这段固定的文本越好预测"是统计上确定的，方向与"随上下文劣化"相反。

相邻深度配对差里只有 13 个区间为正（历史变长后该文本略难），最大的是 int8 的 +0.008138 ± +0.005589（t=+1.46）—— 测不出与零的差别。其余全部为负且多数显著。

所以"上下文越长模型越差"在本模型 + 本语料上不成立。上一版把一条 257K 的自然流一次跑完、看到深层 PPL 升高，那是文本内容造成的（越深的 token 越属于后面那本书），不是深度本身。

注意这条曲线的形状：从 0 到 ~1K 历史收益极陡，之后趋缓；在约 60,517 个 token 处有一次大的台阶（紫线"book 02|03"），那是可见窗口第一次够到目标块所属那本书的开头。此后继续加长历史（包括加进完全不相关的书 01、00）都没有让结果变差。

问题二：KV 量化的代价会不会随上下文增长而放大？

配对差值本身随历史的斜率（正 = 量化代价随上下文放大）：

  • bf16 − fp8：+0.005919 ± +0.007586 nats/十倍程（t=+0.78）
  • fp8 − bf16：-0.005919 ± +0.007586 nats/十倍程（t=-0.78）
  • int8 − bf16：+0.007940 ± +0.007351 nats/十倍程（t=+1.08）
  • int8 − fp8：+0.009823 ± +0.004649 nats/十倍程（t=+2.11）
  • k8v4 − bf16：-0.002792 ± +0.007226 nats/十倍程（t=-0.39）
  • k8v4 − fp8：+0.002498 ± +0.004798 nats/十倍程（t=+0.52）
  • nvfp4 − bf16：-0.006089 ± +0.008548 nats/十倍程（t=-0.71）
  • nvfp4 − fp8：+0.004786 ± +0.005693 nats/十倍程（t=+0.84）

这些斜率即使为正也只有 ~1e-3 nats/十倍程量级，而绝对差值本身在 1e-2 nats 量级 —— 量化代价基本上是一个与上下文长度无关的常数，没有出现"短上下文无损、长上下文崩溃"的拐点。

1. 固定文本的 NLL 随可见历史长度变化

每个点是一次运行：该次运行中目标块 1008 个 token 的 NLL 均值（丢掉块首 16 个 token 以避开分词边界），误差棒为块内标准误。内容完全固定。

紫色虚线是源流里的书边界（pg19 的 00/01/02/03 顺序拼接），横轴从右往左读：点越靠右，历史越短。跨过一条紫线表示可见窗口已经伸进更早的那本书。

2. 相邻深度之间的配对 ΔNLL —— 最直接的答案
